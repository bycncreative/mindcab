缺陷清单

### 缺陷 1：画布内联编辑中 `Esc` 无法取消编辑（中）

- **现象**：双击节点进入标题编辑后，按 `Esc` 无任何反应，改动保留；README 承诺「`Esc` 取消，恢复到进入编辑前的文本」。
- **复现**：双击任意节点 → 输入新文本 → 按 `Esc`。`Enter` 确认正常。
- **根因**：dvui `TextEntryWidget.zig:1261-1270` 将所有未消费的按键标记为 `e.handled`；`main.zig` 帧末的全局快捷键循环开头即 `if (e.handled) continue`，收不到 `.escape`，`app.cmdCancelEdit()` 永远不执行。`Enter` 正常是因为它走控件的 `enter_pressed` 回调，不依赖全局循环。
- **修复建议**：`Esc` 改在控件回调路径处理，或全局循环中对 `.escape` 放行 `e.handled` 检查（编辑态下优先级最高）。

### 缺陷 2：模态对话框按 `Enter` 关闭后按键泄漏到画布（中）

- **现象**：打开「帮助 → 关于」，按 `Enter` 关闭对话框的同一次按键会额外触发一次「添加同级节点」——节点数 +1、标签变脏、状态栏出现「已添加级节点」。自定义三选一确认框（`confirmDisplay`）疑似同样存在。
- **复现**：选中某节点 → 帮助 → 关于 → 按 `Enter` → 观察节点数与脏标记。
- **根因**：对话框关闭后该 `key` 事件未被标记 `handled`，同帧泄漏到 `main.zig` 帧末全局快捷键循环，`ke.action == .down` 且当前 `editing == .none`，落到 `.enter => app.cmdAddSibling()`。
- **修复建议**：对话框消费/关闭的那帧内将对应按键标记 `handled`，或在 `runPendingConfirm()` 消费帧内跳过一次全局按键分发。

### 缺陷 3：多行正文在画布节点上只显示第一行（中）

- **现象**：侧栏「正文描述」输入两行（`第一行正文\n第二行正文`），侧栏与数据均保存两行，但画布节点只渲染第一行，第二行完全不可见，节点高度也不增加。
- **复现**：侧栏正文框输入 `第一行正文` → `Enter` → `第二行正文`，观察画布根节点。
- **根因**：`canvas.zig:350-363` 给正文描述标签的显式 `rect` 高度固定为 `desc_h = App.descFont().textHeight()`（单行行高），宽度为内容宽，dvui 标签按此 rect 绘制，第二行被裁掉；`layout.zig:32-43` 的测量经 `app.zig:measureText` 用 `font.textSize(text)`，对含 `\n` 文本同样未按多行累计高度，节点框因此也不撑高。README 数据格式明确支持 `&#10;` 换行，导出 PNG 走同一渲染路径，同样丢失第二行。
- **修复建议**：测量时按 `\n` 切行累加高度（宽度取最长行），绘制 rect 高度改为多行总高，并确认 dvui 标签换行渲染与该 rect 匹配。

### 缺陷 4：焦点在画布时 `Ctrl+PageUp` / `Ctrl+PageDown` 无法切换标签（中）


- **现象**：焦点位于画布（点击过画布空白/节点）时，`Ctrl+PageUp`、`Ctrl+PageDown` 不切换标签，而是被画布滚动区消费为「键盘滚动一屏」；焦点在工具栏按钮、菜单等其他控件上时两键正常。`Ctrl+Tab` 不受影响（任何焦点下均正常）。
- **复现**：打开两个标签，点一下画布空白 → 按 `Ctrl+PageUp`：视图滚动一屏、标签不变；把焦点移到工具栏按钮后再按则正常切换。
- **根因**：dvui `scrollArea` 处理 `.page_up` / `.page_down` 键做键盘滚动时不检查 Ctrl 修饰，直接标记 `e.handled`；`main.zig:141` 帧末全局循环 `if (e.handled) continue` 因此收不到事件，`main.zig:170` 的 `.page_up => app.cmdPrevTab()` 无法触发。实验佐证：视图在中部时按裸 `PageUp` 页面上滚一屏（C→D 帧对比）；同一基线按 `Ctrl+PageUp` 视图上滚但标签不切换（F→G 帧对比）。
- **修复建议**：在 `main.zig` 全局循环中把带 Ctrl 的 `.page_up` / `.page_down` 提升为应用级快捷键（类似顶部 Ctrl+Z/Y 的先行处理），或让画布滚动区只在无 Ctrl 时消费这两个键。


### 缺陷 5：双击进入内联编辑中, 在这个状态下，再单击，文字仍然处于选中，正确的处理，应是取消全选，光标落在点击处 。另外，文字全选时，如果用户按了右箭头键，光标应在最后，按了左箭头键，光标应在最前。
